# Hamburgueria (Dev Burguer)

Projeto simples de cardápio digital com carrinho e finalização de pedido via WhatsApp.

## Tecnologias

- HTML
- Tailwind CSS
- JavaScript (vanilla)

## Como executar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Gere o CSS do Tailwind em modo desenvolvimento:
   ```bash
   npm run dev
   ```
3. Abra o arquivo `index.html` no navegador.

## Funcionalidades

- Listagem de hambúrgueres e bebidas.
- Adição/remoção de itens no carrinho.
- Cálculo automático do total do pedido.
- Contador de itens no carrinho.
- Validação de endereço antes do checkout.
- Verificação de horário de funcionamento (18h às 22h).
- Envio do pedido formatado para WhatsApp.
